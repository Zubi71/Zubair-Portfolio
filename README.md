# Zubair Bin Zahid — Portfolio

Premium light Next.js portfolio for **zubair.dyznoai.com**.
Palette: #F8FAFC / #FFFFFF / #0B1220 / #4169FF / #64748B / #E2E8F0, dark section #0B1220.

## Run locally
```
npm install
npm run build
npm start
```

## Deploy on Vercel
Vercel project `zubair-portfolio` already exists. A new production deployment
from these files updates it. Domain zubair.dyznoai.com is added in Vercel;
its DNS is managed by the user in OrangeHost (see MEMORY for the CNAME fix).

## Notes
- Project previews are styled browser-frame previews using each live site's
  real homepage headline — they are NOT screenshots. Click "View Live Project"
  to see the actual site.
- No testimonials are shown because none have been verified.
- The contact form submits via WhatsApp (prefilled message), by design —
  there is no email backend, so it does not pretend to send an email.
- Hero uses no portrait: the previous AI placeholder is NOT presented as
  Zubair. Replace the hero visual with his real photo when provided.
